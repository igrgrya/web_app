# Инструкция по ручным шагам (ЛР №1)

Ниже — пошаговые действия, которые нужно выполнить вручную: у них есть
аккаунты и внешние сервисы, к которым у меня нет доступа. Выполнять можно
по порядку.

Адрес репозитория: `https://github.com/igrgrya/web_app`
Предполагаемый публичный адрес сайта: `https://igrgrya.github.io/web_app/`

---

## 1. Включить GitHub Pages (публикация сайта в Интернет)

1. Открой в браузере https://github.com/igrgrya/web_app и войди в свой аккаунт.
2. Сверху нажми вкладку **Settings** (Настройки).
3. В левом меню найди раздел **Pages**.
4. В блоке **Build and deployment** в поле **Source** выбери **GitHub Actions**
   (не «Deploy from a branch»).
5. Ничего сохранять не нужно — выбор применяется сразу.
6. Открой вкладку **Actions** (вверху репозитория). Увидишь запущенный
   workflow **Deploy static site to GitHub Pages**. Дождись зелёной галочки
   (обычно 1–3 минуты). Если workflow не запустился сам — нажми на него и
   кнопку **Run workflow**.
7. После успешной сборки зайди снова в **Settings → Pages** — там появится
   ссылка **Visit site** и адрес вида `https://igrgrya.github.io/web_app/`.
8. Проверь: открой этот адрес, пощёлкай страницы каталога, новостей, форума.
   Если всё открывается — пункт «страницы, доступные через Интернет» закрыт.

**Если что-то не работает:**
- Пустая страница 404 → подожди 2–3 минуты, GitHub Pages разворачивается не мгновенно.
- Workflow красный → открой его, посмотри лог ошибки. Частая причина — Pages
  ещё не переключён на «GitHub Actions» (шаг 4).
- Нужен публичный репозиторий. Если репозиторий приватный, Pages бесплатен
  только для публичных репозиториев: поменяй видимость в **Settings → General →
  Danger Zone → Change visibility**.

## 2. Зарегистрировать сайт в поисковых системах

Это требование методички («включить свою страницу в базу данных одного из
поисковых серверов»). Регистрировать нужно уже рабочий публичный адрес из
пункта 1.

### 2.1. Яндекс

1. Открой https://webmaster.yandex.ru/ и войди через свой Яндекс-аккаунт
   (или создай его).
2. Нажми **Добавить сайт**, введи `https://igrgrya.github.io/web_app/`.
3. Яндекс попросит **подтвердить права**. Самый простой способ — **метатег**:
   он покажет строку вида
   `<meta name="yandex-verification" content="xxxxxxxxxxxxxxxx">`.
   - Скопируй её и передай мне — я вставлю метатег в шаблон и пересоберу сайт.
   - Либо, если у тебя есть доступ к файлам, положишь файл подтверждения сам.
4. После подтверждения зайди в **Индексирование → Файлы Sitemap** и добавь
   `https://igrgrya.github.io/web_app/sitemap.xml` (файл уже создан).
5. Там же в **Индексирование → Переобход страниц** попроси проиндексировать
   главную страницу.

### 2.2. Google

1. Открой https://search.google.com/search-console и войди в Google-аккаунт.
2. **Добавить ресурс → Префикс URL**, введи `https://igrgrya.github.io/web_app/`.
3. Подтверждение — способом **HTML-тег**: получишь строку
   `<meta name="google-site-verification" content="...">`.
   Передай её мне, либо подтверди файлом HTML.
4. После подтверждения: **Файлы Sitemap** → добавь `sitemap.xml`.
5. **Проверка URL** → вставь адрес главной → **Запросить индексирование**.

### 2.3. Bing (по желанию)

1. https://www.bing.com/webmasters — добавь сайт, подтверди метатегом,
   добавь `sitemap.xml`.

> Индексация занимает от нескольких дней до пары недель. Для отчёта достаточно
> скриншота подтверждённого сайта в панели вебмастера.

## 3. Определить рейтинг / позицию сайта (по методичке)

1. Открой http://www.siteposition.ru/check.php, введи адрес сайта и ключевой
   запрос (например, «каталог фондов и акций»). Сохрани результат скриншотом.
2. Открой http://www.site-auditor.ru/index.html и собери данные о видимости
   сайта в Рунете. Сохрани отчёт.
3. Если сервисы недоступны — приложи скриншоты из Яндекс.Вебмастера
   (раздел «Поисковые запросы»), этого достаточно для демонстрации.

## 4. Повторить W3C-валидацию вручную (по желанию)

Проверка уже выполнена автоматически (`node static/validate.mjs` — 28 файлов,
0 ошибок). Чтобы показать преподавателю:

1. Открой https://validator.w3.org/#validate_by_uri.
2. Вставь адрес любой страницы, например
   `https://igrgrya.github.io/web_app/index.html`, и нажми **Check**.
3. Должно быть «No errors or warnings to show» (зелёная плашка).
4. Сделай скриншот для отчёта.

Скриншот нужен для пункта методички «протестированные с помощью валидатора
страницы сайта».

## 5. Что приложить к отчёту

- [ ] Публичный URL сайта (`https://igrgrya.github.io/web_app/`).
- [ ] Скриншот главной страницы.
- [ ] Скриншот счётчика посещений (подвал) и страницы «Статистика посещений».
- [ ] Скриншот рейтинга (в карточке любого инструмента поставь звёзды).
- [ ] Скриншоты сервисов: форум, гостевая книга, поиск, новости, опрос,
      рассылка, календарь, полезные ссылки (минимум пять обязательных).
- [ ] Скриншот валидатора W3C без ошибок.
- [ ] Скриншот подтверждённого сайта в Яндекс.Вебмастере / Google Search Console.
- [ ] (По желанию) результат siteposition.ru / site-auditor.ru.
