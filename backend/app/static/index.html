Лабораторная работа №3 — приложение с доступом к БД

Веб-приложение с динамическим доступом к базе данных: ввод данных (инструменты и котировки), поиск по одному и по двум атрибутам, статистика по секторам, лидеры торгового дня, графики динамики цен и сведения о БД. Backend — FastAPI + SQLAlchemy, СУБД — PostgreSQL, графики — Chart.js. Описание запросов Q1–Q5 — на странице «БД (лаб. №3)» основного сайта.

Каталог инструментов Q1: JOIN + фильтры + сортировка · Q2: поиск

Поиск по одному атрибуту — подстрока тикера или названия (одно поле) либо один фильтр; поиск по двум атрибутам — любые два и более критерия одновременно, например «сектор + подстрока» или «биржа + тип».
