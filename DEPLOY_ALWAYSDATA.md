# Funds Lab: весь сервис на одном бесплатном хостинге

Проверка условий: 6 ноября 2026 года. Выбран **alwaysdata Free**: страницы,
стили, картинки, XML/XSLT, JavaScript, графики, FastAPI, Swagger и PostgreSQL
размещаются **в одном аккаунте alwaysdata**. Сайт открывается с одного адреса
`https://ИМЯ.alwaysdata.net/`. GitHub нужен только для хранения исходников.

## Почему этот вариант

| Вариант | Весь нынешний проект без смены языка и СУБД | Причина выбора / отказа |
| --- | --- | --- |
| **alwaysdata Free** | Да, Python ASGI + PostgreSQL + все страницы | 0 €/мес., 1 ГБ SSD, 256 МБ RAM, ¼ CPU; личные некоммерческие проекты; адрес alwaysdata.net |
| InfinityFree | Нет | PHP и MySQL/MariaDB; FastAPI/Python и PostgreSQL не поддерживаются |
| Render Free | Не подходит для постоянной бесплатной БД | Бесплатный PostgreSQL истекает через 30 дней; Aiven нарушает требование одного хостинга |
| Amvera с начальным балансом | Нет постоянного бесплатного тарифа в прежней схеме | Бонусный баланс — не бесплатное размещение без срока |
| GPT Sites / GitHub Pages | Не рассматриваются | GPT Sites исключён пользователем; Pages не запускает FastAPI/PostgreSQL |

InfinityFree позволяет загружать файлы через FTP/файловый менеджер, однако
ZIP — только способ доставки файлов. Он не добавляет серверу Python или PostgreSQL.
Переписывание приложения на PHP/MySQL возможно как отдельный проект, но для
переноса существующего сервиса это сложнее и создаёт риск потерять требования лабы.

Обратите внимание: старые инструкции проекта про 100 МБ alwaysdata устарели.
В актуальном Free — **1 ГБ**, общий для файлов, баз и почты. Free ограничен
личным некоммерческим использованием и штатным адресом alwaysdata.net.
В разделе Services нельзя запускать отдельные фоновые службы; наш HTTP-сайт
запускается через **Web → Sites → User program**, как требует документация ASGI.
Одного процесса достаточно. PostgreSQL предоставляет сам alwaysdata.

У нового бесплатного аккаунта необходимо входить в панель хотя бы раз в 120 дней,
иначе доступ приостанавливается до входа. Далее интервалы увеличиваются:
[официальные правила](https://help.alwaysdata.com/en/docs/admin-billing/profile/suspension/).

## Что находится в ZIP

`deployment/funds-lab-full.zip` распаковывается в папку `funds-lab/`:

- `web/` — полный текущий сайт: главная, новости, биржи, история, материалы
  новичку, глоссарий, риски, ссылки, контакты, о проекте, поиск, форум,
  гостевая книга, сервисы, XML/XSLT, RSS и лабораторная №3 `/db.html`;
- `backend/` — настоящий FastAPI + SQLAlchemy, семь путей API, графики Q1–Q5;
- `db/migration.sql` — полный снимок **всех 15 таблиц** локального PostgreSQL
  на момент упаковки; не только четыре таблицы каталога;
- `db/schema.sql`, `seed.sql`, `seed_history.sql` — исходная схема и учебные данные;
- `frontend/` и `static/` — исходники предыдущего React-интерфейса и генератора;
- `deploy/` — установка, настройка подключения, импорт, запуск и проверка;
- `MANIFEST.json` — контрольные суммы файлов; `Dockerfile` — запасной
  контейнерный запуск всего сервиса, а не одной лабораторной.

В ZIP нет `.git`, `.env`, паролей, Windows-окружений Python, node_modules,
учётных данных Sites или внешних подключений к Render/Aiven/D1.
Снимок БД содержит данные проекта: архив не следует публиковать как файл сайта.

Гостевая книга, форум, опрос, подписки и счётчик в текущей версии сайта
используют **localStorage браузера**, как и до переноса. Это сохранено.
Перенос хостинга не превращает их в общую серверную базу. Данные localStorage
старого домена браузер автоматически новому домену не передаёт.
Погода и курсы валют по-прежнему запрашиваются у поставщиков данных;
это внешние информационные API, а не дополнительный хостинг частей проекта.

## Публикация: один раз

1. [Зарегистрировать Free](https://www.alwaysdata.com/en/register/?p=2012),
   подтвердить почту. В панели убедиться, что выбран именно **Free 0 €**,
   а не пробный Plus на 30 дней. Имя аккаунта определяет адрес сайта.
2. **Environment → Python**: Python **3.12**.
   **Databases → PostgreSQL**: создать базу `ИМЯ_funds`, версию **18**
   (совпадает с локальным PostgreSQL), дать своему пользователю права на неё.
   Пароль БД вводится только в скрытом запросе установщика.
3. Загрузить ZIP по SFTP в домашнюю папку аккаунта. Параметры подключения —
   **Remote access → SSH/SFTP**; использовать точное имя сервера из панели.
   Затем в SSH распаковать архив:

   ```sh
   python -m zipfile -e funds-lab-full.zip .
   cd funds-lab
   sh deploy/install.sh
   .venv/bin/python deploy/configure.py
   .venv/bin/python deploy/init_db.py
   ```

   `configure.py` спросит имя аккаунта, имя БД, пользователя и пароль.
   Сохранит подключение в `backend/.env` с правами 600; заполнит домен в
   контактах, sitemap и robots. `init_db.py` восстановит все таблицы из снимка
   в одной транзакции и **откажется работать на непустой базе**.
4. **Web → Sites**: изменить стартовый сайт аккаунта или создать сайт с его
   штатным адресом `ИМЯ.alwaysdata.net`:

   | Поле | Значение |
   | --- | --- |
   | Type | **User program** |
   | Working directory | `/home/ИМЯ/funds-lab` |
   | Command | `/home/ИМЯ/funds-lab/.venv/bin/python /home/ИМЯ/funds-lab/deploy/start.py` |

   Программа сама читает обязательные `$IP` и `$PORT` хостинга, включая IPv6.
   Не выбирать WSGI и не запускать приложение как отдельную службу Services.
5. Включить HTTPS в настройках сайта. Проверить с сервера или локально:

   ```sh
   .venv/bin/python deploy/check.py https://ИМЯ.alwaysdata.net
   ```

   Главная — `/`, все разделы — на том же адресе, БД — `/db.html`,
   API — `/api/…`, Swagger без внешнего CDN — `/docs`.
   `/lab3/` перенаправляет на `/db.html`.
6. Повторно проверить **именно новый домен** с российских узлов.
   Пока эти действия не выполнены, архив подготовлен, но перенос не завершён.

## Повторная сборка с актуальными локальными данными

Из корня проекта, в PowerShell (команды не содержат пароль):

```powershell
./backend/.venv/Scripts/python deploy/export_db.py --pg-dump "C:/Program Files/PostgreSQL/18/bin/pg_dump.exe"
./backend/.venv/Scripts/python deploy/fetch_vendor.py
./backend/.venv/Scripts/python deploy/build_bundle.py --snapshot deployment/private/funds.sql
```

Перед сборкой нужны файлы swagger-ui-dist 5.34.1 из официального NPM-пакета
в игнорируемой папке `deploy/vendor/`: swagger-ui-bundle.js, swagger-ui.css,
LICENSE, NOTICE, VERSION.json. `fetch_vendor.py` скачивает их с проверкой SHA-256.
В готовом архиве они уже есть.

## Выполненная локальная приёмка

Архив распакован в отдельную папку, полный снимок восстановлен в новую временную
PostgreSQL 18. У всех 15 таблиц совпали количества строк с исходной базой.
Проверены хеши файлов и отсутствие файлов/строк подключения с паролями.
Повторный импорт на непустую базу отклонён без изменения данных.
Прошли более 100 HTTP-проверок сайта и **58/58** исходных проверок БД/API.
В браузере проверены поиск «ГАЗ», карточка/график GAZP, каталог XML/XSLT
и локальный Swagger. Ошибок JavaScript при проверке графика нет.
Готовые Linux-пакеты зависимостей для Python 3.12 доступны (15 wheel-файлов).
Проверки не означают, что сайт уже опубликован: фактический перенос требует
аккаунта, загрузки и проверки конечного публичного домена.

При обновлении существующего сайта **не выполнять повторный импорт БД**.
Сначала сохранить текущую БД и `backend/.env`, обновить код и `web/`, затем
перезапустить сайт через панель. Старый хостинг отключать после приёмки нового.
