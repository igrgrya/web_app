Обмен данными: RSS-лента и форматы экспорта

Лабораторная работа №4 — «Организация обмена данными между приложениями». Приложение извлекает новости из базы данных и отдает их другим приложениям в форматах обмена (CSV, XML, ASCII с XML-тегами), а также загружает внешний RSS-файл из Интернета и объединяет его с новостями БД на странице «Объединенные новости».

Содержание

  • Этапы работы
  • Структура формата RSS 2.0
  • Форматы обмена (форма отчетности)
  • Внешний RSS и объединенные новости
  • Импорт внешних новостей в БД
  • Лента сайта

Этапы работы

  1. Изучить протокол передачи новостных данных RSS (см. следующий раздел).
  2. Разработать структуру формата передачи на основе XML — лента новостей в формате RSS 2.0.
  3. Доработать приложение: извлечение новостей из БД в структуру формата обмена (эндпоинты ленты и экспортных форматов).
  4. Произвести прикладную обработку файла: загрузить внешний RSS из Интернета, объединить его с новостями БД и загрузить разобранные записи в таблицу imported_news.

Структура формата RSS 2.0

RSS (Really Simple Syndication) — формат обмена новостными данными: XML-документ, в котором канал <channel> содержит метаданные ленты и набор элементов <item> (новостей). Дата публикуется по стандарту RFC-822, все тексты экранируются по правилам XML.

<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0">
  <channel>                                  — канал: сама лента
    <title>Funds Lab — новости рынка</title>   — название ленты
    <link>…news.html</link>                    — сайт-источник
    <description>Новости рынка…</description>   — описание канала
    <language>ru</language>
    <lastBuildDate>Mon, 20 Sep 2026 00:00:00 +0300</lastBuildDate>
    <item>                                     — элемент: одна новость
      <title>Заголовок новости</title>
      <link>адрес новости на сайте</link>
      <guid isPermaLink="true">уникальный идентификатор</guid>
      <pubDate>дата по RFC-822</pubDate>
      <description>текст новости</description>
      <category>тикер связанного инструмента</category>
    </item>
    …
  </channel>
</rss>

Внешний RSS и объединенные новости

По схеме обмена из методички: приложение скачивает внешний RSS-файл, разделяет его на элементы и объединяет с новостями БД «Новости», вставляя результат в подготовленный web-шаблон.

    Импорт внешних новостей в БД

    Загрузка полученных данных в СУБД: разобранные записи внешнего фида сохраняются в таблицу imported_news (дубликаты отсекаются по паре «источник + идентификатор записи»).

    Лента сайта

    Адрес ленты — /rss.xml: динамическая RSS 2.0-лента прямо из базы данных, поэтому подписчики всегда видят актуальные новости. Ленту можно добавить в любой RSS-ридер или агрегатор новостей. В заголовке каждой страницы есть <link rel="alternate" type="application/rss+xml"> — ридеры находят ленту автоматически.
