# Funds Lab — облачная версия

Исходники опубликованного сайта: https://funds-lab3-igrgrya.wisecurry19.chatgpt.site/
Раздел лабораторной №3: /db.html (прежний адрес /lab3/ также работает).

- public/ — страницы сайта, общий макет, интерфейс и локальные библиотеки.
- worker/index.js — серверные запросы к облачной базе D1.
- worker/seed.json — согласованная копия четырёх учебных таблиц без реквизитов подключения.
- drizzle/ — схема облачной базы.
- .openai/hosting.json — идентификатор существующего Sites и привязка базы.

Из этой папки: `node scripts/build.mjs`, затем `node scripts/test.mjs` и
`node scripts/validate-artifact.mjs`. Нужен Node.js 24 с node:sqlite.
Результаты dist/ не добавляются в Git.

Изменения сохраняются в GitHub по правилам проекта: dev → Pull Request → main.
Push в GitHub пока не запускает публикацию Sites. После проверки нужно отдельно
опубликовать эту версию в существующий проект Sites, сохранив project_id.
Служебный checkout hosted-lab3/ хранится отдельно и игнорируется основным Git.
Перед следующей публикацией перенесите изменённые исходники из hosting/ в этот
checkout, не затрагивая его .git. Не переносите пароли и временные credentials.

Облачная и локальная PostgreSQL не синхронизируются автоматически.
GitHub Pages по-прежнему публикует папку site/, а не эту облачную версию.
