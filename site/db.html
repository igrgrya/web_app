Лабораторная работа №3 — приложение с доступом к БД

Динамическое веб-приложение поверх базы данных PostgreSQL: каталог инструментов, поиск, агрегаты по секторам, лидеры торгового дня и графики динамики цен. Backend — FastAPI + SQLAlchemy, данные хранятся в PostgreSQL, фронтенд приложения построен на Chart.js.

Открыть приложение (при запущенном backend: backend/start.bat → http://127.0.0.1:8000)

GitHub Pages отдаёт только статические файлы, поэтому серверная часть запускается локально: backend/start.bat (или uvicorn app.main:app из каталога backend). Интерактивная документация API — Swagger UI на /docs.

Типы запросов к базе данных

Пять типов SQL-запросов, реализованных в приложении
№ Запрос SQL-приёмы Где в интерфейсе
Q1Каталог инструментовSELECT с JOIN четырёх таблиц, фильтры, сортировкаТаблица каталога (клик по заголовку колонки)
Q2Поиск по тикеру и названиюПараметризованный ILIKE с экранированиемСтрока поиска над таблицей
Q3Агрегаты по секторамGROUP BY, COUNT / AVG / SUMСтолбчатая диаграмма и таблица
Q4Лидеры роста и паденияORDER BY + LIMITДве таблицы «лидеры дня»
Q5Карточка инструмента и история ценВыбор по ключу, срез последних датЛинейный график и карточка

Структура таблиц

Схема базы данных funds_lab (db/schema.sql)
Таблица Содержимое Связи
exchangesБиржи: код, название, страна, часовой пояс1—M instruments
sectorsСекторы экономики1—M instruments
instrumentsКаталог: тикер, название, тип, биржа, сектор, валютаFK → exchanges, sectors
price_snapshotsСнимки цен: цена, изменение, объём, датаFK → instruments

Исходники приложения: каталог backend/ репозитория (модели — app/models.py, запросы — app/main.py, схема и тестовые данные — db/). Графики построены на локальной копии Chart.js, без внешних CDN.
